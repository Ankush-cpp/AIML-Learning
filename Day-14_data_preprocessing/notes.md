# Data Insights & Recommendation System

## Overview

This project demonstrates how cleaned user data can be analyzed to generate meaningful insights and basic product recommendations.

The system performs:
- Data cleaning
- Insight generation
- Rating-based recommendation

It simulates a simple real-world data analytics pipeline used in AI/ML systems.

---

## Features

### Data Cleaning
- Removes duplicate users
- Handles missing values
- Standardizes inconsistent ratings

### Data Insights
- Calculates average product rating
- Finds percentage of poor ratings
- Counts users with good ratings

### Recommendation System
- Generates product recommendations based on user ratings
- Uses simple rule-based recommendation logic
