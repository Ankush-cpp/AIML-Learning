# SQL Rollback & Savepoint

## Topics Covered

- ROLLBACK
- SAVEPOINT
- ROLLBACK TO SAVEPOINT
- COMMIT
- Transactions

## Technologies Used

- MySQL

COMMIT
→ Changes permanently save

ROLLBACK
→ Transaction ke changes undo

SAVEPOINT
→ Transaction ke beech ek checkpoint

ROLLBACK TO SAVEPOINT
→ Sirf us checkpoint ke baad wale changes undo

## Key Learning

Learned how ROLLBACK can undo transaction changes and how SAVEPOINT can create checkpoints inside a transaction for partial rollback.
