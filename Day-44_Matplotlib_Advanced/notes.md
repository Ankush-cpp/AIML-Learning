# Day-44: Matplotlib Advanced

Today I learned advanced plotting concepts using Matplotlib.

## Topics Covered

- Histograms
- Multiple Datasets on Histogram
- axvline in Histogram
- Box Plots
- Operations on Box Plot
- Stack Plots
- Subplots
- Modern Matplotlib

## Key Concepts

### Histogram
Used to visualize the distribution and frequency of numerical data.

### Multiple Datasets on Histogram
Multiple datasets can be plotted together to compare their distributions.

### axvline
Used to add a vertical reference line to a plot.

### Box Plot
Used to understand data distribution, spread, median, and outliers.

### Stack Plot
Used to visualize how multiple quantities contribute to a total over time.

### Subplots
Used to display multiple plots inside a single figure.

### Modern Matplotlib
Uses the object-oriented approach with `fig` and `ax` for better control over plots.
